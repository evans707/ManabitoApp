# 課題情報一元管理Webサービス「マナビト」

![manabito_icon](./image/manabito_icon.png)

## 1. 主な機能
- 課題情報の集約
- カレンダー表示
- 課題の検索・フィルタリング

## 2. 技術構成

### ◯フロントエンド
- Vue.js
- Vite
- Pinia
- Vue-Router

### ◯バックエンド
- Django
- Django REST Framework
- Celery
- Scrapy

### ◯データベース
- SQLite 

### ◯インフラ
- Docker
- Nginx
